Viva questions


How does label processing work?
The first pass counts only real instructions. A label stores the current count, so it points to the next instruction and takes no space.


How are variables given addresses?
In the second pass, a symbol that is not in the table is a new variable. It gets 16, then 17, 18 and so on.


How does screen memory work?
Row r starts at 16384 + 32r. One word is 16 pixels, -1 makes them black and 0 clears them.


How do I move the box down by n rows?
Change @17408 to 17408 + 32n. For a wider box, change @1 in ROWLOOP to the number of words.


A mistake I fixed
The Assembler page said “different lengths” for Max.asm. My Max.hack had all 16 lines. The page showed Steps: 1, because the single-step button assembles one instruction per click. Using fast-forward fixed it.
